Install and initialise

React Native. Pass storage in — a measurement library is a guest in someone else's app — and a CSPRNG, which React Native does not ship.
npm install @mmp/react-native @react-native-async-storage/async-storage react-native-get-random-values
import "react-native-get-random-values"; // must be the first import
import { NativeModules } from "react-native";
import { MMP, adaptKeyValueStore, createNativeBridge } from "@mmp/react-native";
import AsyncStorage from "@react-native-async-storage/async-storage";

await MMP.initialize(
  { apiKey: "YOUR_SDK_KEY", endpoint: "{{ tracking_domain }}" },
  {
    storage: adaptKeyValueStore(AsyncStorage),
    native: createNativeBridge(NativeModules.MmpNative),
  },
);

initialize sends install, app_open and session events itself. Do not send them from track().

3

Track events

Constants for every event this app defines or receives, so names in code match names in reports. Edit the list under Events.
{{ event_constants }}
await MMP.track(Events.ADD_TO_CART, { properties: { item_id: "A-1", quantity: 1 } });
await MMP.track(Events.PURCHASE, { revenueMinor: 499, currency: "USD", properties: { order_id: "o-42" } });
await MMP.setUserId("user-42"); // sends signup or login for you

Money is integer minor units — cents, paise — with a currency. Floats are refused.

4

Server to server

For purchases you validate on your own backend. Uses an s2s key and a signed request; see the API docs for the signature.
curl -X POST {{ tracking_domain }}/v1/s2s/events \
  -H "authorization: Bearer YOUR_S2S_KEY" \
  -H "content-type: application/json" \
  -H "x-mmp-timestamp: $(date +%s)" \
  -H "x-mmp-signature: <hmac-sha256 of METHOD\nPATH\nTIMESTAMP\nSHA256(body)>" \
  -d '{"events":[{"event_name":"purchase","anonymous_id":"device-abc","revenue_minor":499,"currency":"USD"}]}'
